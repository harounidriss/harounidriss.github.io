# Portfolio scientifique

Portfolio de **Ahmat Haroun Idriss**, diplômé d'un Master 2 de mathématiques appliquées (Modélisation et Analyse Numérique, Université de Montpellier, 2025).

🔗 Site : https://harounidriss.github.io/

## À propos

Je travaille sur la modélisation mathématique et la simulation numérique d'EDP : éléments finis, volumes finis et problèmes inverses. J'ai réalisé un stage de recherche sur la modélisation électromagnétique d'une métasurface pour le géoradar (COMSOL Multiphysics, UMR EMMAH, INRAE – Avignon Université). Je me forme aussi à l'intelligence artificielle scientifique, notamment aux réseaux de neurones informés par la physique (PINNs).
